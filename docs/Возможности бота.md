# Telegram-бот — возможности и история доработок

Бот — собственный код (`bot.py` + `docs.py` + `reminders.py`), а не готовый продукт: Python без внешних библиотек, кроме faster-whisper для голоса. Написан агентом Claude под нашу систему с 2026-11-05. Готовые решения (официальный плагин Anthropic «Telegram channel», claude-tg и др.) не подошли: в них нет голосовых, подписи документов, писем, Codex и защиты от вредных инструкций.

Этот файл — единственное место, где перечислены возможности бота и что в нём менялось. Каждая доработка бота: строка в «Историю», правка «Возможностей», `bot.py` здесь — копия с живого сервера с метками вместо личных данных.

## Возможности (на 2026-11-08)

| Что | Как работает |
|---|---|
| Текст | `claude -p --resume <диалог>` в рабочей папке: правила `CLAUDE.md` действуют и в боте |
| Голосовые, аудио, кружки | ffmpeg → faster-whisper (small, int8, ru) → текст показывается в чате → агенту |
| Фото, файлы, видео | сохраняются в `06_Загрузки/`, альбом — одним сообщением; офисные файлы — PDF-копия для чтения |
| Остальные типы (стикер, геоточка, контакт, опрос, пересланное «расширенное» сообщение с таблицами) | содержимое передаётся агенту как данные (JSON без служебных полей), бот не отказывает |
| Новый диалог | кнопка «🆕 Новый чат» под каждым ответом агента или команда `/new` |
| Вернуться в прошлый диалог | «Ответить» (свайп) на любой ответ агента — бот продолжает тот диалог, в котором ответ написан, и делает его текущим; агент видит цитату. Бот помнит последние 500 ответов (`msgmap_<chat>` в `state.json`); ответы до 2026-11-08 19:21 не помнит. Ответ на сообщение без пометки — цитата идёт в текущий диалог |
| Оформление ответов | Markdown агента → HTML Telegram: жирный, курсив, код, ссылки, заголовки, списки; не прошло — отправка простым текстом. Подпись «🟡 Clodex · Claude/Codex» |
| Отправить файл | агент пишет строку `SEND_FILE: путь` |
| Переложить файл | блок `MOVE_FILE / From: / To: / END_MOVE`: только внутри рабочей папки, без перезаписи, без удаления, не трогает служебные файлы и папки с точкой; отчёт в чат |
| Письмо | блок `EMAIL_DRAFT` → черновик в чате → отправка после «да» (или в «Черновики» Gmail, если хостер закрыл почтовые порты) |
| Подписать документ | блок `SIGN_DOC` → `docs.py` вписывает текст и ставит подпись, присылает картинку страницы и PDF |
| `/help` | список команд и подсказки; команды есть и в меню Telegram по кнопке «/» (`setMyCommands` при запуске бота) |
| Лимиты подписки Claude | бот вызывает `claude -p --output-format stream-json --verbose` и забирает событие `rate_limit_event`: % лимита на 5 часов и на неделю, время обнуления. `/limits` — показать; ≥ 80 % — предупреждение под ответом с советом `/codex`; лимит кончился — время обнуления в сообщении об ошибке. Лимиты Codex не показываются |
| Codex | `/codex` и `/claude` — кто отвечает; диалоги раздельные, очередь общая |
| Ответ на утреннюю сводку и «Вопрос дня» | бот добавляет к сообщению пункты сводки или задачу, агент правит базу задач |
| Напоминания на точное время | «напомни в 20:30 выпить таблетку» (голосом или текстом) → агент выводит блок `REMIND` (Text, At или In, Repeat: none/daily/weekdays/weekly/monthly) → бот хранит в `reminders.json` и показывает «⏰ Напомню …» с кнопкой «Отменить». В нужную минуту (проверка раз в 20 с, время московское) — сообщение с кнопками «Готово», «10 мин», «1 час», «Завтра»; без нажатия повторяет 2 раза через 15 мин. Пропущенные, пока бот лежал, приходят сразу с пометкой «опоздал». Отмена голосом — блок `REMIND_CANCEL`; список — `/reminders` или слово «напоминания». Время «сейчас» бот пишет агенту в начале каждого сообщения |
| `/status` или слово «статус» | статус системы скриптом `status.py`, без ИИ (работает и при кончившемся лимите), с кнопками; внизу — лимиты Claude |

Права агента в боте: чтение и запись только в рабочей папке и памяти Claude, без командной строки (Bash), код бота и `/root` закрыты. Всё, что требует команд, — отложенная задача (правила задач, «Глоссарий»).

## Чего пока нет

- Таблицы в ответах (новый формат сообщений Telegram для ботов не проверен).
- Сборка пульта и снимок экрана из бота.
- Запись в приложение «Напоминания» iPhone: с сервера доступа нет (варианты — в задаче системы про напоминания).

| 2026-11-08 | `/status` и слово «статус» — статус системы скриптом `status.py`, без ИИ: проверки сторожа, время последних и следующих запусков по расписанию, фоновые разборы; кнопки «Запустить разбор …» и «Убрать конфликтные копии в архив» | статус от ИИ проверял не всё и при кончившемся лимите не работал; разборы запускаются только по нажатию, сами — никогда |
| 2026-11-08 | «Ответить» (свайп) на ответ агента продолжает тот диалог, где он написан; агент видит цитату | после кнопки «Новый чат» можно вернуться к любому прошлому разговору |
| 2026-11-08 | `/help`, `/limits`, меню команд, предупреждение при ≥ 80 % лимита | видно, сколько осталось от подписки и когда переключиться на Codex |
| 2026-11-08 | Напоминания на точное время: `reminders.py`, блоки `REMIND` / `REMIND_CANCEL`, кнопки «Готово» и «Отложить», повторы, `/reminders` | агент не мог «напомнить в 20:30 выпить таблетку»; вся связь — в одном окне бота |
| 2026-11-08 | Баланс трёх опор: `balance.py` раз в час считает долю времени с агентом за 7 дней — работа, личное, система (только разговоры, начатые человеком), против целей из `04_Системные файлы/10_Баланс опор — правила.md`; строка в утренней сводке, полоска на личном пульте, итог для агента в `01_Главный контекст/04_Баланс опор.md`. После первой выкладки — `systemctl enable --now balance.timer` | владелец увлекается одной опорой; нужна подсказка «пора заняться другим» |
